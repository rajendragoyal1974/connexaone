# Connexa Infotech portable static website

Upload the contents of this folder to any static host. No build command or server runtime is required.

## Hosting

- GitHub Pages: upload these files to a repository and choose the repository root as the Pages source.
- Netlify / Cloudflare Pages / Vercel: deploy this folder with no build command and `.` as the output directory.
- Shared hosting: upload all files into `public_html` or the document root.
- Local preview: open `index.html`, or use any small static file server.

The Static Editor saves data in the current browser only. Exported JSON is a backup; permanent hosted changes require updating `data.js` and uploading it again.
